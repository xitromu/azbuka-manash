# Азбука с Манашем

Браузерная игра для обучения ребёнка русскому алфавиту: ведущие — капибара Манаш и аксолотль Лота. Ребёнок знакомится с 33 печатными буквами, слушает названия и звуки, собирает слова и получает мандаринки за задания, на которые покупает подарки Манашу.

Игра — один файл `index.html`, без библиотек и сборки. Открывается на компьютере, планшете и телефоне. Прогресс хранится в `localStorage` браузера.

## Что внутри

- По порядку: все 33 печатные буквы, затем повторение вразнобой.
- Задания разного типа: звук, слово, картинка, сборка и мини-игры.
- Мандаринки за задания и подарки для Манаша.
- Голос ведущих: синтез речи устройства (русский голос). Подсказки, повтор и отключение звука — кнопками в игре.
- Офлайн-открытие после первого визита по HTTPS: страница и картинка капибары кешируются.

## Запуск

Можно открыть `index.html` как файл. Для офлайн-кеша и добавления на экран «Домой» нужен HTTP(S)-сервер:

```bash
C:\TST\python.exe -m http.server 8775 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8775/index.html`.
